# TrialGuide demo

Interactive demo of TrialGuide (Team Zenith, IIIT Hyderabad, LMA course project). The main page
replays decisions recorded from the real system on three development patients from the TREC 2021
and SIGIR 2016 cohorts. "Try your own patient" opens a live page where you paste a note, upload
one, or start from a few facts, and answer TrialGuide's questions as the doctor. On this free CPU
Space the live page uses a word-matching stand-in in place of the two models.
Code and results: https://github.com/Pakkabhabad18/trialguide

Research prototype, not for clinical use.
